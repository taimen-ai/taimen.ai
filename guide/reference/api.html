    Core service APIs¶

    The list of HTTP API operations of the three core services, taken from their OpenAPI at the superproject's submodule revisions. The "Edge" column shows how the operation is reachable from outside through Caddy (Edge and TLS): a public path or "internal network only" (the IAM administrative surface, metrics, all of memory-service).

    Full request and response schemas are in the services' own OpenAPI: https://<public address>/openapi.json for Control Plane, /iam/openapi.json for IAM; memory-service, from inside the compose network.
