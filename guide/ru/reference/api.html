    API сервисов ядра¶

    Перечень операций HTTP API трёх сервисов ядра, снятый с их OpenAPI на ревизиях сабмодулей суперпроекта. Колонка «Периметр» — как операция доступна снаружи через Caddy (Периметр и TLS): публичный путь или «только внутри сети» (административная поверхность IAM, метрики, memory-service целиком).

    Полные схемы запросов и ответов — в OpenAPI самих сервисов: https://<публичный адрес>/openapi.json для Control Plane, /iam/openapi.json для IAM; memory-service — изнутри сети compose.
